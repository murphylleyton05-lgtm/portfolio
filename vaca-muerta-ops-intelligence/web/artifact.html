Capa Power BI

El modelo de datos, listo para Power BI

Los mismos datos que ves acá quedan en esquema estrella (una tabla de hechos rodeada de dimensiones) en /data. Importás los CSV, marcás las relaciones y armás estas medidas DAX.

ESQUEMA

dim_operador ─┐ dim_area ─────┤ dim_pozo ─────┼─< fact_produccion dim_fecha ────┤ (pozo × mes: oil, gas, agua) └─< fact_actividad (mes: spuds, completions)

MEDIDAS DAX (EJEMPLOS)

Petroleo bbl/d = DIVIDE( SUM(fact_produccion[petroleo_bbl]), 30.4 )
Oil acumulado = CALCULATE( SUM(fact_produccion[petroleo_bbl]), FILTER( ALL(dim_fecha), dim_fecha[mes] <= MAX(dim_fecha[mes]) ))
Var MoM % = VAR ant = CALCULATE([Petroleo bbl/d], PREVIOUSMONTH(dim_fecha[fecha])) RETURN DIVIDE([Petroleo bbl/d] - ant, ant)
Pozos activos = DISTINCTCOUNT( fact_produccion[pozo_id] )

El set completo de medidas está en powerbi/medidas-dax.md.

Lo que este tablero no hace

Los límites, declarados.

Los datos son simulados

Producción, actividad y operadores salen de un generador con semilla fija. El proyecto hermano vaca-muerta-analytics usa los datos oficiales reales de la Secretaría de Energía.

Es una vista de operaciones, no de reservas

Muestra producción y actividad. La estimación de reservas (EUR) y la validación de curvas viven en el proyecto de analytics.

El costo es un estimado

La inversión por pozo se estima por longitud de rama y etapas; no son costos contables reales.

El .pbix no está incluido
