Capa Power BI

El modelo de datos, listo para Power BI

La fuente es la producción oficial por pozo y mes (produccion.parquet) más una dimensión de pozos (pozos.parquet). Power BI importa parquet directo; marcás las relaciones y armás estas medidas DAX.

ESQUEMA

dim_pozo (pozos.parquet) id_pozo, empresa, area, ventana_fluido, primer_mes │ 1 │ * ▼ fact_produccion (produccion.parquet) id_pozo, fecha, empresa, prod_petroleo_m3, prod_gas_mm3

MEDIDAS DAX (EJEMPLOS)

Petroleo bbl/d = DIVIDE( SUM(fact_produccion[prod_petroleo_m3]) * 6.28981, 30.4 )
Oil acumulado (MMbbl) = DIVIDE( CALCULATE( SUM(fact_produccion[prod_petroleo_m3]) * 6.28981, FILTER( ALL(dim_fecha), dim_fecha[fecha] <= MAX(dim_fecha[fecha]) )), 1e6 )
Var MoM % = VAR ant = CALCULATE([Petroleo bbl/d], PREVIOUSMONTH(dim_fecha[fecha])) RETURN DIVIDE([Petroleo bbl/d] - ant, ant)
Pozos activos = DISTINCTCOUNT( fact_produccion[id_pozo] )

El set completo de medidas está en powerbi/medidas-dax.md.

Lo que este tablero no hace

Los límites, declarados.

Producción real y oficial

Los datos son los de la Secretaría de Energía (producción de pozos no convencionales), los mismos que usa vaca-muerta-analytics. El CI los regenera automáticamente.

Es una vista de operaciones, no de reservas

Muestra producción y actividad. La estimación de reservas (EUR) y la validación de curvas viven en el proyecto de analytics.

"Actividad" = primera producción

El dataset no trae fecha de spud; la actividad se mide por el mes en que cada pozo entra en producción, que es un proxy fiel de la actividad de completación.

El .pbix no está incluido

Se entregan los datos (parquet) y las medidas DAX para reconstruir el reporte en Power BI Desktop en minutos.
