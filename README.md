## 📌 Entregable del checkpoint — Pipeline ETL (Power BI)

**➡️ [Pipeline ETL — TechStore](./pipeline-etl-techstore-powerbi)** · Power BI · Power Query · M

Pipeline ETL que va de datos crudos a un modelo confiable: perfila la calidad de los
datos, resuelve los problemas intencionales (duplicados, nulos y tipos), aplica la
nomenclatura `Dim_ / Fact_`, enriquece la tabla de hechos con un **Merge** y documenta
toda la lógica en **lenguaje M**. Incluye el entregable final `Pipeline_ETL_Murphy_Lleyton.pbix`,
el dataset con los problemas, el código M de las 4 consultas y la documentación completa.

> Todo el detalle y las justificaciones técnicas están en el **[README del proyecto](./pipeline-etl-techstore-powerbi/README.md)**.
