Lo que este tablero no hace

Los límites, declarados.

Data Analytics, no ingeniería de confiabilidad

Es analítica de datos aplicada a Asset Reliability, no un análisis RCM/FMEA formal ni un dictamen de un ingeniero de confiabilidad.

Los datos son simulados

La flota, las fallas y las variables salen de un generador con semilla fija. La etiqueta de falla se construyó a partir de esas variables, así que el modelo aprende una señal real pero sintética.

Un modelo simple y transparente

Regresión logística sobre variables agregadas, no series temporales de sensores en alta frecuencia. Se eligió por ser interpretable, no por ser el más potente.

Predice riesgo, no la causa raíz

Dice qué activo mirar primero; el modo de falla y la causa se confirman con inspección.

Proyecto de portfolio · Data Analytics aplicado a Asset Reliability · datos simulados con Python (numpy). Los CSV quedan en esquema estrella (dim_/fact_), listos para Power BI, y el modelo se entrena aparte en scripts/modelo.py.
